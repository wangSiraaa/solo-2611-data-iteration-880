# 导览面板与排字（合成）

在 730 的断链路线（r1→r2 把 P2 基标 300 改 330）上叠加导览印制流程：

- 面板 G1 有独立修订 g1→g2→g3。条带绑定目录版本+区段+合法标签半开窗，
  等比例映到纸面；S-pq-rev 为逆排；S-dup-p1 与 S-dup-p2 是两个区段上的
  同一标签窗 [340,360)，物理位置不同，锚点也不同。
- 标注单必须指明条带与设施身份：报告没有该设施、条带目录版本与报告不符、
  物理位置落在窗外，都会给出具体原因。
- 排字台例题：条带 [0,10) 顺排到纸面 0..10，P@2、Q@5，贴法都是
  [锚点,锚点+3)；P 必印、Q 价值 4，两框相接都可印（LN1）。禁印 [7,8)
  后只印 P（LN2）。纸面终点改 8（g2）后锚点成 8/5 与 4，两框重叠，
  重出后也只印 P。
- 印版 PLATE-1 当日冻结；纸面小改（g2）只重出受影响的行（LN1、LN2），
  LN3、LN5 原样带入 PLATE-2。旧单 T1 在纸张改版与目录改版后仍可离线复查、
  复印。
